# Preuves examinables

Les fichiers de ce dossier proviennent d'exécutions locales sur données fictives. Ils peuvent être reproduits avec les commandes du README ; ce ne sont pas des certifications ou des attestations externes.

- `docker-tests.txt` : sortie des tests lancés dans un conteneur Docker.
- `deterministic.json` : cinq scénarios et un rejeu sur quatre conteneurs MCP indépendants. Les décisions de ce pilote sont scriptées, sans modèle.
- Les résultats et traces du modèle local seront documentés ici une fois l'évaluation terminée.

Les traces montrent les arguments et les résultats, pas une chaîne de pensée privée. Les textes de demandes sont des fixtures, y compris le message hostile. Un test de cette fixture ne permet pas de généraliser à toutes les attaques possibles.
